# CISM Governance: NIS2 Directive Compliance Blueprint

## 1. Governance & Leadership Mandate
* **Board Approval:** Management must explicitly approve and monitor all security controls.
* **Mandatory Training:** Executive leadership must complete documented cyber-risk education.
* **Personal Liability:** Non-compliance risks personal executive fines and temporary managerial bans.

## 2. Multi-Stage Incident Response Workflow
| Timeline | Report Phase | Mandatory Content |
| :--- | :--- | :--- |
| **T + 24 Hours** | Early Warning | Initial notification; specify if suspected malicious intent or cross-border threat. |
| **T + 72 Hours** | Incident Update | Intermediate assessment, severity analysis, and known indicators of compromise. |
| **T + 1 Month**  | Final Report | Complete event timeline, full impact analysis, and Root Cause Analysis (RCA). |

## 3. Core Technical Controls Checklist
1. [ ] **Asset Management:** Comprehensive mapping of all network information systems.
2. [ ] **Zero Trust Baseline:** Implementation of MFA, network segmentation, and continuous authorization.
3. [ ] **Supply Chain (TPRM):** Security risk-assessments and audit clauses embedded in all vendor MSAs/SLAs.
4. [ ] **Resilience Architecture:** Documented BCP, secure off-site backup handling, and emergency communication channels.
