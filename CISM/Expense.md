# CISM Finance: Expense Types in Security

## 1. Capital Expenditures (CapEx)
*   **Purpose:** Long-term investment in security infrastructure.
*   **Example:** Purchasing a fleet of hardware security modules (HSM).
*   **Key Concept:** Depreciation (spreading the cost over the asset's useful life).

## 2. Operating Expenditures (OpEx)
*   **Purpose:** Sustaining the security program's daily functions.
*   **Example:** Monthly AWS GuardDuty fees, penetration testing services.
*   **Key Concept:** Scalability (easier to increase/decrease than CapEx).

## 3. Hidden Costs (The "Soft" Expenses)
*   **Downtime:** Revenue lost during system outages.
*   **Reputational Damage:** The cost of losing customer trust (difficult to quantify but critical).
*   **Compliance Penalties:** Fines from regulators (GDPR, HIPAA) resulting from under-investment.
