# CISM Operations: Endpoint Detection and Response (EDR)

## 1. Definition
A security solution that continuously monitors end-user devices to detect and respond to advanced cyber threats.

## 2. Key Benefits to the ISM
*   **Blast Radius Reduction:** Automated host isolation prevents an APT from moving laterally to other network segments.
*   **Decoupled Visibility:** Because agents sit on the host, they monitor activity even when employees are working remotely off the corporate network.
*   **Forensic Goldmine:** Provides timeline reconstruction during Root Cause Analysis (RCA).

## 3. Critical EDR Capabilities
1. **Network Isolation:** Disconnects the machine from the network while maintaining the EDR management channel.
2. **Process Rollback:** Undoes changes made by ransomware or malicious scripts.
3. **Remote Shell:** Allows incident responders to securely access the endpoint CLI to investigate.
