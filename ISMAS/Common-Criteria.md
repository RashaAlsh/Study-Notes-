ISO/IEC 15408 (Common Criteria)

Overview

Security devices such as firewalls, access control systems, and other protective technologies act as gatekeepers for an organization’s information assets.

Because these products play a critical role in protecting systems and data, their security capabilities should be independently verified.

ISO/IEC 15408, also known as Common Criteria, provides a standardized framework for evaluating and certifying the security of IT products.

⸻

What is ISO/IEC 15408 (Common Criteria)?

Definition

ISO/IEC 15408 is an international standard used to evaluate the security features and assurance of IT products.

It provides a structured process where:

* Users define their security requirements
* Vendors describe the security features of their products
* Independent testing laboratories verify vendor claims

⸻

Common Criteria Evaluation Process

The evaluation process involves three main parties:

1. Users

Users define:

* Required security capabilities
* Protection needs
* Risk requirements

Example:

An organization may require a firewall to support:

* Access control
* Logging
* Network protection

⸻

2. Vendors

Vendors provide:

* Product security claims
* Security documentation
* Technical evidence

They explain how their product meets required security objectives.

⸻

3. Testing Laboratories

Independent laboratories evaluate the product to confirm:

* Security claims are accurate
* Controls operate correctly
* Product meets evaluation requirements

⸻

Evaluation Assurance Level (EAL)

Overview

Products evaluated under Common Criteria receive an Evaluation Assurance Level (EAL) rating.

The EAL indicates the depth and rigor of security evaluation performed.

Ratings range from:

EAL 1 → Basic assurance
...
EAL 7 → Highest assurance

⸻

EAL Levels

EAL 1 – Functionally Tested

Provides basic confidence that:

* Security functions exist
* The product operates as described

⸻

EAL 7 – Formally Verified Design and Tested

Provides the highest level of assurance.

Requires:

* Extensive testing
* Detailed analysis
* Formal verification methods

Used for highly sensitive environments.

⸻

Purpose of EAL Ratings

EAL ratings help organizations:

* Compare security products
* Select solutions appropriate for their risks
* Understand the level of confidence provided by testing

A higher EAL generally means:

* More detailed evaluation
* More rigorous testing
* Greater assurance

⸻

Why Common Criteria Matters

Common Criteria helps ensure security products are:

Properly Tested

Products are evaluated using a recognized international framework.

Trustworthy

Organizations gain confidence that security claims have been independently reviewed.

Suitable for Protecting Information

Products can be selected based on:

* Business requirements
* Security risks
* Required protection level

⸻

Risk-Based Product Selection

Organizations should not automatically choose the highest EAL product.

Instead, they should select products based on:

* Information sensitivity
* Threat environment
* Business requirements
* Cost and complexity

Example:

A government system protecting highly classified information may require stronger assurance than a small internal network.

⸻

Relationship to Information Security

Common Criteria supports security decision-making by providing assurance that security products perform as expected.

It helps organizations make informed choices when selecting:

* Firewalls
* Access control systems
* Security appliances
* Other IT security products

⸻

Summary

ISO/IEC 15408 (Common Criteria) provides a trusted method for evaluating and certifying the security of IT products.

It ensures that:

* Users can define security requirements
* Vendors can demonstrate security capabilities
* Independent laboratories can verify product claims

Evaluation Assurance Levels (EAL 1–EAL 7) indicate the level of testing and confidence provided.

Organizations should select security products with an appropriate EAL level based on their risk and security requirements.
