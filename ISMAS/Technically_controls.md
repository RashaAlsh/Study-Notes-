# ISO/IEC 27001:2022 Annex A.8 Technological Controls – MD Perspective

| Control | MD Purpose |
|----------|-----------|
| A.8.1 User endpoint devices | Protect laptops, desktops, mobile devices, and other endpoints from compromise. |
| A.8.2 Privileged access rights | Control high-risk administrative access to critical systems. |
| A.8.3 Information access restriction | Ensure access to information is limited to authorized users. |
| A.8.4 Access to source code | Protect intellectual property and prevent unauthorized code changes. |
| A.8.5 Secure authentication | Strengthen identity verification and reduce unauthorized access. |
| A.8.6 Capacity management | Ensure systems have sufficient resources to support business operations. |
| A.8.7 Protection against malware | Prevent, detect, and respond to malicious software threats. |
| A.8.8 Management of technical vulnerabilities | Identify and remediate security weaknesses before exploitation. |
| A.8.9 Configuration management | Maintain secure and consistent system configurations. |
| A.8.10 Information deletion | Ensure information is securely removed when no longer needed. |
| A.8.11 Data masking | Protect sensitive data from unauthorized exposure. |
| A.8.12 Data leakage prevention | Prevent unauthorized disclosure of sensitive information. |
| A.8.13 Information backup | Protect business data and support recovery from loss or disruption. |
| A.8.14 Redundancy of information processing facilities | Ensure critical services remain available during failures. |
| A.8.15 Logging | Record activities for monitoring, investigations, and accountability. |
| A.8.16 Monitoring activities | Detect suspicious or unauthorized activities promptly. |
| A.8.17 Clock synchronization | Ensure accurate timestamps for monitoring and investigations. |
| A.8.18 Use of privileged utility programs | Control tools that could bypass security controls. |
| A.8.19 Installation of software on operational systems | Prevent unauthorized or unsafe software deployment. |
| A.8.20 Networks security | Protect networks supporting business operations and communications. |
| A.8.21 Security of network services | Ensure network services are securely delivered and managed. |
| A.8.22 Segregation of networks | Limit the spread of threats by separating network environments. |
| A.8.23 Web filtering | Reduce exposure to malicious or inappropriate online content. |
| A.8.24 Use of cryptography | Protect confidentiality, integrity, and authenticity of information. |
| A.8.25 Secure development life cycle | Ensure security is built into software development processes. |
| A.8.26 Application security requirements | Define security expectations for applications before development or acquisition. |
| A.8.27 Secure system architecture and engineering principles | Design systems that are resilient and secure by default. |
| A.8.28 Secure coding | Reduce software vulnerabilities through secure programming practices. |
| A.8.29 Security testing in development and acceptance | Identify security weaknesses before systems go live. |
| A.8.30 Outsourced development | Ensure third-party developers meet security requirements. |
| A.8.31 Separation of development, test and production environments | Reduce the risk of unauthorized changes and data exposure. |
| A.8.32 Change management | Control changes to systems and services to minimize risk. |
| A.8.33 Test information | Protect sensitive data used during testing activities. |
| A.8.34 Protection of information systems during audit testing | Ensure audits do not compromise system security or availability. |

## Executive Summary

The Annex A.8 Technological Controls help management:

- Protect systems, networks, applications, and data.
- Reduce cyberattack and malware risks.
- Secure software development and system changes.
- Detect and respond to suspicious activities.
- Maintain system availability and resilience.
- Safeguard sensitive and business-critical information.
- Support business continuity and operational reliability.

**In one sentence:** Annex A.8 ensures that the technology supporting the business is secure, resilient, monitored, and capable of protecting information throughout its lifecycle.
